近日书 7

· 2026-01-03 · # 近日书 # 发现

2025太过于忙碌，太过于疲惫，工作占据了太多的时间，几乎没太多精力读书。

  • 君主论 : 拿破仑批注版：对于不懂那段历史的人而言，只算看了半本。
  • 献给阿尔吉侬的花束：虽然从第一行开始就向着注定的结局奔去，但依然令人感动。
  • 面纱：纠缠至死。
  • 金枝 : 跨越万年的人性进化故事：很喜欢这种宗教或巫术习俗的现实主义起源解读。
  • 试刊号：一种阴谋论。
  • 小径分岔的花园：很多年后终于读完了这本书，一本迷宫的花园。
  • 随机漫步的傻瓜 : 发现市场和人生中的隐藏机遇：这个作者写的书我都不是很喜欢。
  • 土星之环：出差在酒店里，跟着作者徒步。
  • 克林索尔的最后夏天：西方想象中的东方酒神。
